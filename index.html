팀원 공유 시 주소 링크 주의사항

🚨 왜 팀원 컴퓨터에서 파일이 안 열릴까요?
현재 브라우저 주소(file:///...)는 내 컴퓨터 로컬 드라이브의 개인 파일 경로입니다. 다른 사람의 컴퓨터나 스마트폰에서는 내 컴퓨터 C드라이브 파일에 접근할 수 없으므로 "파일을 찾을 수 없음 / 열 수 없음" 오류가 발생합니다.
💡 가장 쉽고 확실한 해결 방법: [완성된 HTML 리포트 다운로드]
1. 상단 [📝 피드백 노트 & 리포트 다운로드 ➔] 버튼을 클릭하여 피드백 페이지로 이동합니다.
2. 상단의 [📥 완성된 HTML 리포트 다운로드 (.html)] 버튼을 클릭합니다.
3. 다운로드된 단일 파일(.html)을 카카오톡, 사내 메신저(슬랙/잔디) 또는 이메일에 파일 첨부로 보내세요!
4. 팀원은 전달받은 파일을 더블클릭만 하면 인터넷 없이도 모든 그래프와 분석 결과를 완벽하게 열어볼 수 있습니다.
🛡️ 데이터 미저장 보안 모드 안내
본 시스템은 고객 및 화원사 데이터 보호를 위해 엑셀 데이터를 외부 서버(DB)에 저장하지 않고 브라우저 메모리에서만 즉시 분석합니다. 따라서 웹 주소만 전송할 경우 다른 팀원의 화면에는 데이터가 비어있게 되므로, 반드시 다운로드된 리포트 파일로 공유하셔야 분석 결과가 온전히 전달됩니다.
